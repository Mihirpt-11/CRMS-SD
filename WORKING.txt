ADMIN CREATES A LAB RESOURCE
🧑‍💼 Admin Action
Admin → Dashboard → “Add Resource” (lab/classroom).
Frontend → NGINX
POST /booking/resource
NGINX → Booking Service
Booking Service
Validates input
Stores resource in MongoDB (resources collection)
Booking service → Redis
Invalidates cache (so updated resource list appears instantly)
Response → Frontend
Admin sees “Resource created successfully”.


Student selects resource → chooses time → “Create Booking”.
🔄 System Workflow
Frontend → NGINX
Booking Service
Validates time
Checks Redis for availability
Stores booking in MongoDB
Publishes event to RabbitMQ:
booking.created
RabbitMQ → Notification Worker
Worker consumes event:
prints log like “Booking Created for User X”
(can be extended to send email)
Frontend
Shows “Booking created!” and updates dashboard.
